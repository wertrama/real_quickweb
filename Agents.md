# NaarWeb Studio redesign instructions

## Project goal

Redesign this small-business website using a trustworthy and premium
Forest & Gold identity.

The website brand name is:

NaarWeb Studio

Primary message:

Websites that move your business forward.

The website is intended for small local businesses that need a clear,
professional and affordable website.

## Brand colours

Use these CSS variables:

--forest: #1A3A2A;
--forest-dark: #10261B;
--emerald: #2D6A4F;
--gold: #D4A017;
--gold-dark: #B8890C;
--cream: #F5F0E8;
--white: #FFFFFF;
--forest-soft: #E3ECE6;
--gold-soft: #F6EBCB;
--text-main: #1A3A2A;
--text-muted: #5D685F;
--border: #D9D2C5;

## Colour usage

- Forest: navigation, headings, footer and important dark sections.
- Gold: primary calls to action, prices and small premium details.
- Emerald: icons, tags, links and secondary accents.
- Cream: main page background.
- White: cards and content surfaces.
- Use forest text on gold buttons.
- Do not use white text on the primary gold button.
- Do not overuse gold.

## Typography

- Use Manrope for headings and brand text.
- Use Inter for paragraphs, navigation, forms and supporting text.
- Keep typography clear, modern and restrained.

## Design style

- Trustworthy, premium, calm and approachable.
- Avoid flashy gradients, excessive shadows and excessive animations.
- Use generous spacing.
- Use consistent border radiuses.
- Use subtle borders and shadows.
- The design must remain suitable for local service businesses.
- The website must not look like a cryptocurrency or luxury jewellery site.

## Development rules

- Work on only the requested section.
- Do not redesign unrelated sections.
- Preserve existing functionality.
- Do not remove content unless explicitly instructed.
- Reuse existing components where practical.
- Do not install new packages unless necessary.
- Before installing a package, explain why it is needed.
- Keep components reasonably small and maintainable.
- Make every section responsive.
- Check desktop, tablet and mobile layouts.
- Maintain accessible colour contrast.
- Use semantic HTML.
- Add visible keyboard focus states.
- Respect prefers-reduced-motion for non-essential animations.

## Workflow

For every task:

1. Inspect the relevant existing code.
2. Briefly explain the proposed changes.
3. Modify only the necessary files.
4. Run the available build, lint or test commands.
5. Report:
   - files changed;
   - what changed;
   - commands run;
   - any remaining problems.

Do not modify files before understanding the existing structure.
